The "Ask" Box (Environment Verification Summary)

Every homework (HW), machine problem (MP), and term-project milestone (make verify in HW 12) must build and run deterministically inside the course's pinned CPU DevContainer without requiring a GPU.

Required Verification Artifacts (HW 1 & MP 2):

  1. Build the pinned Dockerfile (docker build -t cis531-runtime:mp2 .).
  2. Run verify_env.py inside the container (docker run --rm cis531-runtime:mp2 python verify_env.py) and confirm the exact SHA-256 runtime digest:
    6f0648c69f69b1faeb96cfecaa7e2a904ed9210c8c07e0b5dd13d2f9df25ff75
  3. Run probe_compute.py to log whether your environment is running on the CPU-Only Fallback Baseline or an optional GPU Acceleration Overlay.

1. Two-Tier Container Architecture & Digest Pinning Policy

To guarantee 100% reproducibility across Windows 11 laptops, Apple Silicon Macs, Linux workstations, and campus/national HPC clusters, CIS 531/731 enforces a Two-Tier DevContainer Policy:

  • Tier 1 (Canonical CPU DevContainer - Mandatory Baseline): Normative grading baseline. 100% of coursework is solvable on CPU using faiss-cpu and Whisper base / base.en. Built on python:3.10-slim-bullseye.
  • Tier 2 (GPU Acceleration Profile - Optional Overlay): Optional performance acceleration on Beocat, PSC Bridges-2, or personal NVIDIA GPUs for batch Whisper (small.en / turbo) or large embeddings.

2. Host Prerequisites & Docker Desktop Setup (Windows 11 + WSL 2)

  • Operating System: Windows 11 (Build 26200+), macOS 13+, or Ubuntu 22.04+ Linux.
  • WSL 2 Kernel: WSL 2 (6.18+) with hardware virtualization enabled (verify via PowerShell: wsl --status).
  • IDE & Extensions: Visual Studio Code with Dev Containers, Docker, and Remote - SSH extensions.

Docker Desktop Quick Configuration

  1. General Settings: Set Virtual Machine Manager to WSL 2 and enable use containerd for pulling and storing images.
  2. WSL Integration: Enable integration with your default WSL distro under Resources → WSL integration and apply changes.
  3. Daemon Smoke Test: Run docker --version and docker run --rm hello-world in your WSL 2 terminal.

3. Pinned Runtime Specification

All submissions must match pinned package versions in the course manifest; unpinned versions fail verification.

Canonical Course Dockerfile

FROM python:3.10-slim-bullseye

RUN apt-get update && apt-get install -y --no-install-recommends \
    build-essential \
    openjdk-11-jre-headless \
    ffmpeg \
    git \
    sudo \
    && rm -rf /var/lib/apt/lists/*

ENV JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64
ENV PYSPARK_PYTHON=python3
ENV PIP_NO_CACHE_DIR=1

RUN pip install --upgrade pip && \
    pip install \
    pyspark==3.5.1 \
    torch==2.2.1 \
    transformers==4.38.2 \
    openai-whisper==20231117 \
    mlflow==2.11.1 \
    faiss-cpu==1.8.0

ARG USERNAME=vscode
ARG USER_UID=1000
ARG USER_GID=$USER_UID
RUN groupadd --gid $USER_GID $USERNAME \
    && useradd --uid $USER_UID --gid $USER_GID -m $USERNAME -s /bin/bash \
    && echo $USERNAME ALL=\(root\) NOPASSWD:ALL > /etc/sudoers.d/$USERNAME \
    && chmod 0440 /etc/sudoers.d/$USERNAME

USER $USERNAME
WORKDIR /workspace

4. Verification & Quota Fallback Protocols

SHA-256 Manifest Verification (verify_env.py): Ensures exact library version parity yielding the required SHA-256 digest string.

Compute Probe (probe_compute.py): Checks whether CUDA is active or if the environment is running on the CPU-Only Fallback Baseline.

API Quota Gateway & CPU Fallback: External LLM/ASR services are accessed via team-scoped LiteLLM proxy virtual keys enforcing rate limits and budgets. If quotas are exhausted, pipelines must fall back to local CPU execution (openai-whisper and SentenceTransformer) inside the DevContainer.
