Course Overview

This course provides a rigorous, hands-on introduction to modern programming techniques and software architectures for scalable data science and responsive analytics. Structured around the five-stage OSEMN data-science lifecycle (Obtain → Scrub → Explore → Model → iNterpret), the curriculum progresses from distributed tabular and stream processing in PySpark 3.5 LTS and reproducible Docker DevContainers to dense vector indexing (FAISS / Milvus), local speech transcription (OpenAI Whisper), retrieval-augmented classification (RAG), generational drift convolutions, and MLflow deployment.

Fall 2026 Responsive Analytics Mandate: Legacy sentiment-analysis grinds (Yelp review corpora and SEC filings) are strictly prohibited. Teams commit to one of two tracks: Track 1 (ASR Stream Ingestion) or Track 2 (Vector Database & Trope Ontologies).

Prerequisites:

  • Programming & Data Structures: Proficiency in Python 3 and undergraduate data structures (CIS 300 / CIS 501 or equivalent).
  • Mathematics & Statistics: Introductory probability and statistics (STAT 510 / STAT 703 or equivalent) and linear algebra fundamentals.
  • System Requirements: Ability to run the pinned CPU DevContainer (Docker Desktop + VS Code). 100% of coursework is solvable on CPU; a dedicated GPU is never required.
  • Programming: Proficiency in Python 3 (functions, classes, basic numpy/pandas) is assumed.
