1. Prerequisites Checklist

Ensure your host workstation meets or exceeds the following baseline specifications:

  • Operating System: Windows 11 (Build 26200+ or higher)
  • WSL Kernel: WSL 2 (Kernel version 6.18+ or higher)
  • IDE & Tooling: VS Code with the Dev Containers extension installed
  • Hardware Virtualization: Enabled in system BIOS/UEFI

To check your exact WSL configuration, run wsl --status in PowerShell.

2. Docker Desktop Configuration

Step 2.1: General Settings Verification

  1. Open Docker Desktop and click the Settings (gear icon) in the top-right header.
  2. Select General from the right-hand panel.
  3. Set Choose Virtual Machine Manager (VMM) to WSL 2.
  4. Set Use containerd for pulling and storing images to On.

Step 2.2: WSL Integration Enablement

  1. In the Settings panel, navigate to WSL integration.
  2. Toggle Enable integration with my default WSL distro to On.
  3. Click Apply & Restart Engine at the bottom right to commit the daemon changes.

4. MP 2 Environment & Digest Verification

To satisfy the strict version manifest for MP 2, verify your container configurations:

4.1 Verification Script (verify_env.py)

import sys
import hashlib

def verify_environment():
    try:
        import torch
        import transformers
        import mlflow
        import faiss
        import whisper
    except ImportError as e:
        print(f"FAILED: Missing module - {e}")
        return

    env_str = f"torch-{torch.__version__}_transformers-{transformers.__version__}_mlflow-{mlflow.__version__}_faiss-{faiss.__version__}"
    digest = hashlib.sha256(env_str.encode('utf-8')).hexdigest()
    print(f"Environment String: {env_str}")
    print(f"SHA-256 Digest: {digest}")

if __name__ == "__main__":
    verify_environment()

4.2 Build Container & Compute Digest

5. Compute Allocation Probing (Part 2)

Run probe_compute.py inside your container runtime to verify fallback routing:

import torch

def probe_compute():
    if torch.cuda.is_available():
        device_name = torch.cuda.get_device_name(0)
        print(f"GPU Pool Active - Batch Embedding/Whisper Ready ({device_name})")
    else:
        print("CPU-Only Fallback Active")

if __name__ == "__main__":
    probe_compute()
