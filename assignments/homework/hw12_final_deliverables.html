Part 1: Final Technical Report (REPORT.pdf)

(15.0 Points)

Use the Generative AI Kit to help structure your submission. Verify every number in your draft against the MLflow export before final PDF assembly.

Required Document Structure (≤ 8 pp writeup + bibliography max; ≤ 4 pp appendix/screenshots besides reported results)

  • Problem, Data, and Provenance: Abstract, problem statement, track, related work, and the provenance of every source (license_class or whitelist id; no Yelp or SEC-filing data, INV-1).
  • Methods and Architecture: Architecture, invariants enforced with contract excerpts, and component versions keyed to the course manifest (INV-14).
  • Evaluation: Gold-standard report (count, codebook, effort), IAA with CIs or validation-fraction evidence, metrics with 95% CIs, ablations, significance tests with multiple-comparison control, cohort-stratified results, and error analysis.
  • Ethics, Limitations, and Reflection: PS 11 findings carried forward with the mitigations actually implemented; what you would change; which invariants proved hardest.
  • Reproducibility, MLOps, and Serving: make verify results, MLflow lineage and registry entry, serving path, and the drift-monitoring runbook.
  • GenAI Audit: Reference to your GenAI.pdf log covering tools used outside the AI Kit.

Part 2: Reproducible Pipeline & MLOps (hw12-final)

(15.0 Points)

Objective: Build a digest-pinned, MLflow-tracked pipeline that reproduces every reported number from raw admitted data on the CPU baseline.

  1. Integration Audit: Reconcile every upstream artifact against the final repository state. Build make verify for lockfile/image-digest checks, contract tests, and the gold-standard range gate.
  2. MLflow Lineage and Registry: Log parameters, metrics, artifacts, git SHA, data hash, and lockfile hash for every run; register the final model with a version and stage.
  3. Serving and Monitoring: Document a checkpointed Structured Streaming job (ASR track) or HTTP/CLI service with a smoke test (VDB track). Include a drift check (PSI or KS) with an alert threshold and runbook.

Deliverable: The full reproducibility package committed under Git tag hw12-final.
