1. Self-Contained DevContainer Bring-Up Runbook & Full-Dependency Specification

Every assignment and term-project milestone in CIS 531/731 is designed to run inside a reproducible CPU DevContainer so that results are identical across Windows 11 (WSL 2), macOS (Intel and Apple Silicon), Linux laptops, and campus HPC clusters. A dedicated GPU is optional and is never required to earn full credit.

1.1 Host Machine Preparation (Windows 11 + WSL 2 + Docker Desktop)

  1. Verify WSL 2 on Windows 11 (or Terminal on macOS/Linux): Ensure hardware virtualization is enabled in BIOS/UEFI and that WSL 2 is active by running wsl --status in PowerShell (confirm Default Version is 2).
  2. Configure Docker Desktop for WSL 2:
    • Open Docker Desktop → Settings (Gear Icon) → General and ensure Choose Virtual Machine Manager (VMM) is set to WSL 2 and Use containerd for pulling and storing images is set to On.
    • Open Settings → Resources → WSL integration, toggle Enable integration with my default WSL distro to On, and click Apply & Restart Engine.
  3. Verify Daemon Connectivity: Open your WSL 2 terminal (or macOS/Linux shell) and run: 
    docker --version
docker run --rm hello-world
    Confirm that the container prints Hello from Docker! without permission or socket errors.

1.2 Why We Extend the Minimal Dockerfile (Course-Wide Dependency Additions)

The minimal starter Dockerfile installs the six core verification packages (pyspark==3.5.1, torch==2.2.1, transformers==4.38.2, openai-whisper==20231117, mlflow==2.11.1, and faiss-cpu==1.8.0). To execute Jupyter notebooks interactively inside the container, forward the Spark Web UI on port 4040 to your host browser, and support all downstream labs (Sentence Transformers, UMAP, HDBSCAN, Plotly, and Streamlit), we add the following explicit enhancements while keeping the four core SHA-256 verification packages locked to their exact versions:

  • Port Exposure (EXPOSE 4040 8888 8501): Exposes the Spark Web UI (4040), JupyterLab server (8888), and Streamlit dashboard port (8501) so http://localhost:4040 opens directly in your host browser for the HW 1 screenshot.
  • NumPy 1.x ABI Pin (numpy==1.26.4): Prevents binary ABI incompatibilities with compiled C++/Cython extensions in faiss-cpu==1.8.0 and torch==2.2.1.
  • Interactive Notebook & Analytics Stack: Adds pinned versions of jupyterlab==4.1.5, ipykernel==6.29.3, pandas==2.2.1, scipy==1.12.0, scikit-learn==1.4.1.post1, sentence-transformers==2.6.1, umap-learn==0.5.5, hdbscan==0.8.33, plotly==5.20.0, streamlit==1.32.2, and requests==2.31.0.
  • Note on PySpark Version Compatibility: The course container pins pyspark==3.5.1 (the Long-Term Support line paired with openjdk-11-jre-headless) to guarantee deterministic compatibility across all labs. Both pyspark 3.5.x (container baseline) and pyspark 4.x use the identical SparkSession and StructType API required for HW 1 Part 1.

# ==============================================================================
# CIS 531/731 (Fall 2026): Full-Dependency CPU DevContainer Dockerfile
# Preserves exact SHA-256 verification digest:
#   6f0648c69f69b1faeb96cfecaa7e2a904ed9210c8c07e0b5dd13d2f9df25ff75
# ==============================================================================
FROM python:3.10-slim-bullseye

# 1. Install System Dependencies (OpenJDK 11 for PySpark, FFmpeg for Whisper, procps for ps)
RUN apt-get update && apt-get install -y --no-install-recommends \
    build-essential \
    openjdk-11-jre-headless \
    ffmpeg \
    git \
    curl \
    procps \
    sudo \
    && rm -rf /var/lib/apt/lists/*

# 2. Configure Java, PySpark, and Pip Environment Variables
ENV JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64
ENV PYSPARK_PYTHON=python3
ENV PYSPARK_DRIVER_PYTHON=python3
ENV PIP_NO_CACHE_DIR=1

# 3. Install Core Pinned Manifest Packages (DO NOT ALTER VERSIONS)
#    Required for deterministic SHA-256 digest in verify_env.py
RUN pip install --upgrade pip==24.0 && \
    pip install \
    pyspark==3.5.1 \
    torch==2.2.1 \
    transformers==4.38.2 \
    openai-whisper==20231117 \
    mlflow==2.11.1 \
    faiss-cpu==1.8.0

# 4. Install Complete Course Notebook, Embedding, UMAP & Dashboard Dependencies
RUN pip install \
    numpy==1.26.4 \
    pandas==2.2.1 \
    scipy==1.12.0 \
    scikit-learn==1.4.1.post1 \
    sentence-transformers==2.6.1 \
    umap-learn==0.5.5 \
    hdbscan==0.8.33 \
    plotly==5.20.0 \
    streamlit==1.32.2 \
    jupyterlab==4.1.5 \
    ipykernel==6.29.3 \
    requests==2.31.0 \
    pytest==8.1.1

# 5. Create Non-Root DevContainer User (vscode)
ARG USERNAME=vscode
ARG USER_UID=1000
ARG USER_GID=$USER_UID
RUN groupadd --gid $USER_GID $USERNAME \
    && useradd --uid $USER_UID --gid $USER_GID -m $USERNAME -s /bin/bash \
    && echo $USERNAME ALL=\(root\) NOPASSWD:ALL > /etc/sudoers.d/$USERNAME \
    && chmod 0440 /etc/sudoers.d/$USERNAME

# 6. Expose Spark Web UI (4040), JupyterLab (8888), and Streamlit (8501)
EXPOSE 4040 8888 8501

USER $USERNAME
WORKDIR /workspace

2. Model Solution — Part 1: Environment Verification (9.0 / 9.0 Points)

To earn full credit (9.0 / 9.0 pts on the 30-point normalized scale), your Part 1 submission must initialize a local SparkSession bound to port 4040, enforce an explicit StructType schema with at least one StringType and one IntegerType field, display a 3-row DataFrame using .show(), and capture a side-by-side screenshot showing the notebook output alongside the active Spark Web UI (http://localhost:4040/jobs/).

from pyspark.sql import SparkSession
from pyspark.sql.types import StructType, StructField, StringType, IntegerType, DoubleType

# 1. Initialize SparkSession and explicitly bind the Spark Web UI to port 4040 across container interfaces
spark = (
    SparkSession.builder
    .appName("CIS531_731_HW1_Env_Verification")
    .master("local[*]")
    .config("spark.ui.enabled", "true")
    .config("spark.ui.port", "4040")
    .config("spark.driver.bindAddress", "0.0.0.0")
    .getOrCreate()
)

# 2. Define an explicit StructType schema (containing StringType, IntegerType, and DoubleType fields)
hw1_schema = StructType([
    StructField("chunk_id", StringType(), nullable=False),
    StructField("track_domain", StringType(), nullable=False),
    StructField("release_year", IntegerType(), nullable=False),
    StructField("token_count", IntegerType(), nullable=False),
    StructField("confidence_prior", DoubleType(), nullable=False),
    StructField("text_excerpt", StringType(), nullable=False),
])

# 3. Populate 3 rows of domain-representative records and execute the .show() action
hw1_rows = [
    ("chk_001", "Track 1: ASR Caller Stream", 2026, 18, 0.94, "Caller from Manhattan requests an up-tempo indie anthem for a late-night drive."),
    ("chk_002", "Track 2: VDB Lyric Corpus",  1917, 14, 0.98, "What passing-bells for these who die as cattle? Only the monstrous anger of the guns."),
    ("chk_003", "Track 2: VDB Lyric Corpus",  2024, 16, 0.91, "Sometimes it feels like our entire generation is running out of time before summer ends."),
]

df_hw1 = spark.createDataFrame(hw1_rows, schema=hw1_schema)
df_hw1.printSchema()
df_hw1.show(truncate=False)
