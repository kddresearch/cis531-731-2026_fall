Part 1: The Scrub Pipeline & Hyphenation Parsing

(15 Points)

In data science, sloppy text normalization destroys semantic relationships downstream. You must utilize PySpark SQL functions to clean a dirty dataset while retaining critical domain-specific syntax.

Tasks:

  • Execute the entirety of the Lab 2 PySpark notebook (lab02.ipynb) in your local or containerized SparkSession.
  • Modification Requirement: Edit the regexp_replace function in Part 2 of the notebook. The default regex strips all special characters. You must update the regex string to specifically retain hyphenated compound words (e.g., ensuring large-scale remains a single token rather than becoming largescale or splitting into large and scale).
  • Generate and print the final TF-IDF sparse vector representation containing your correctly hyphenated tokens.

Part 2: ASR to VDB Integration (The "Obtain" Stage)

(15 Points)

Objective: Prove end-to-end integration by taking raw audio, converting it to text via a local model, mapping it to latent space, and retrieving it via semantic similarity.

  1. Execute Lab 3a to download the public-domain WWI Poetry archive (.zip), extract Wilfred Owen's "Anthem for Doomed Youth," and load the Whisper base model to successfully transcribe the audio.
  2. Execute Lab 3b to initialize the all-MiniLM-L6-v2 embedder and the FAISS index.
  3. Integration Task: Take the exact result["text"] variable generated by your Whisper model in Lab 3a, and paste it into the designated integration block in Lab 3b so it is embedded alongside the existing mock corpus.
  4. Execute a semantic query searching for the concept "doomed youth" and verify that it retrieves the LibriVox transcript.
  5. CIS 731 (Graduate) Extension: Instead of hardcoding the FAISS index in memory, write a function that saves the FAISS index to disk (faiss.write_index) after ingestion, then loads it back into memory to perform the query.

Deliverable: Commit your completed Jupyter Notebooks (.ipynb files) containing the executed cell outputs for both Part 1 and Part 2. Submit the link to your GitHub Pull Request on Canvas.
