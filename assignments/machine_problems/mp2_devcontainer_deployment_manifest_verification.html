Part 1: DevContainer Build & Manifest Pinning

(15 Points)

Initialize your local or remote workspace using the provided Docker DevContainer configuration. You must modify the base configuration to achieve absolute compliance with the strict version manifest provided in the starter repository.

Tasks:

  • Deploy the provided DevContainer image. Edit the requirements to strictly pin PySpark 3.5.x, PyTorch 2.x, and the exact releases of Transformers, OpenAI Whisper, MLflow, and FAISS.
  • Execute the environment verification script (verify_env.py) provided below to generate and output your environment's SHA-256 digest. This digest must match the course standard exactly.

The Verification Script (verify_env.py)

Create a file named verify_env.py in your root directory, paste the following code, and execute it via your terminal (python verify_env.py) once your DevContainer is built.

import sys
import hashlib

def verify_environment():
    try:
        import torch
        import transformers
        import mlflow
        import faiss
        import whisper
    except ImportError as e:
        print(f"FAILED: Missing module - {e}")
        return

    # Extract versions
    env_str = f"torch-{torch.__version__}_transformers-{transformers.__version__}_mlflow-{mlflow.__version__}_faiss-{faiss.__version__}"
    
    # Generate SHA-256 Digest
    digest = hashlib.sha256(env_str.encode('utf-8')).hexdigest()
    print(f"Environment String: {env_str}")
    print(f"SHA-256 Digest: {digest}")

if __name__ == "__main__":
    verify_environment()
