## [Lecture 34: Presenting Results: Ethics & Data Storytelling](../../lectures/lecture_34.md) (Mon 16 Nov 2026)

1. **Technical Storytelling:** Structuring analytical reports and presentations for clarity, impact, and audience alignment.
2. **Ethical Data Presentation:** Avoiding misleading visual scales, cherry-picked metrics, and biased sample reporting.
3. **Communicating Uncertainty:** Transparently presenting confidence intervals, error bounds, and model limitations to stakeholders.
4. **Effective Documentation Structure:** Organizing technical findings following established writing essentials
5. **Audience Adaptation:** Translating complex algorithmic mechanics into actionable insights for diverse domains.
* **Assigned Reading:** [Last, *Technical Writing Essentials* (Chs. 1–3)](https://pressbooks.bccampus.ca/technicalwriting/)

---

## [Lecture 35: Documentation, Provenance & Notebook Presentation Standards](../../lectures/lecture_35.md) (Wed 18 Nov 2026)

1. **Reproducible Notebooks:** Architecting Jupyter notebooks that execute cleanly from top to bottom without hidden state dependencies
2. **FAIR Data Principles:** Ensuring findability, accessibility, interoperability, and reusability for all generated research assets
3. **Provenance Tracking:** Documenting data lineages, software versions, and hyperparameter configurations.
4. **Open-Access Publishing Standards:** Preparing code and data artifacts for public release repositories.
5. **Clean Code Narratives:** Integrating Markdown commentary and code cells to form a cohesive computational argument.
* **Assigned Reading:** [Jupyter Notebook Documentation](https://jupyter-notebook.readthedocs.io/); [Wilkinson et al., *The FAIR Guiding Principles*](https://www.nature.com/articles/sdata201618)

## [Lecture 36: Dashboard Design & Limitations Panel Workshop; Wrap-Up](../../lectures/lecture_36.md) (Fri 20 Nov 2026)

1. **Dashboard Architecture:** Designing intuitive, high-performance visualization panels for model monitoring
2. **Cognitive Load in Visuals:** Minimizing clutter and maximizing data-ink ratios in operational displays.
3. **Limitations Panel Workshop:** Peer-reviewing student-led limitation disclosures and ethical impact statements.
4. **Module 11 Wrap-Up:** Synthesizing technical communication, FAIR compliance, and data storytelling standards.
5. **Phase Transition:** Preparing for Fall Break and the release of PS 11.
* **Assigned Reading:** [Wilke, *Fundamentals of Data Visualization* (Parts I–II)](https://clauswilke.com/dataviz/); [Last, *Technical Writing Essentials*](https://pressbooks.bccampus.ca/technicalwriting/)
