Module 02: Cloud Tools, DevContainers & AI/LLM Tooling

Data Scrubbing, Docker Environments, Inference Runtimes, and LLM Orchestration

Module Overview

Module 02 establishes the environment reproducibility, cloud tooling, and AI infrastructure required for advanced data science pipelines. Students transition from raw data ingestion to systematic data scrubbing (Miner & Shook Ch. 5) and statistical profiling. We then eliminate the "it works on my machine" dilemma by implementing containerized development workspaces via Docker and VS Code DevContainers. Finally, we survey the modern AI/LLM tooling stack—evaluating proprietary APIs versus open-weight models (Llama 3), hardware VRAM quantization constraints, local inference engines (Ollama, vLLM), RAG orchestration (LangChain), and responsible epistemic verification under the "Upper Beam" engineering standard.

🎯 Learning Objectives

  • Apply PySpark 4 transformations for data scrubbing, semantic text chunking, and EDA baseline profiling.
  • Configure reproducible development environments using Docker `Dockerfile` build scripts and VS Code DevContainers.
  • Navigate the AI tooling stack, balancing proprietary APIs against open-weight local execution, VRAM quantization, RAG pipelines, and code verification.
