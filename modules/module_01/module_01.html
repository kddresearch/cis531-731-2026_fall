Module 01: PySpark Intro & Experiment Design

RDDs, DataFrames, PySpark 4 Architecture, and the OSEMN Pipeline Framework

Module Overview

Module 01 introduces foundational distributed computing concepts using PySpark 4. Students transition from local single-node pandas scripts to horizontal cluster computing using Driver and Executor topologies. You will learn the mechanics of lazy evaluation, Directed Acyclic Graphs (DAGs), DataFrame schema enforcement via StructType, and the 5-stage OSEMN pipeline framework (Obtain, Scrub, Explore, Model, Interpret). Additionally, students will formally lock in their Term Project tracks (ASR Live Stream vs. VDB Text Corpora) and complete their Multidimensional Matrix task allocations.

🎯 Learning Objectives

  • Master PySpark RDDs, DataFrames, Catalyst Query Optimization, and lazy evaluation via DAGs.
  • Enforce strict StructType schemas to establish fail-fast mechanics and handle corrupt records.
  • Formulate term project pipelines by selecting an immutable data track (ASR/VDB) and allocating matrix task ownership.
