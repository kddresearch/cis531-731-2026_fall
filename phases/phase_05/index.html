Phase 5: Evaluate & Deploy

Phase Overview

Phase 5 focuses on evaluation, model interpretation, data storytelling, MLOps/AIOps deployment, and special topics. It covers student-built gold-standard evaluation, retrieval/WER metrics, dashboard presentations, final project wrap-up, and Dead Week syntheses. Includes Fall Break (Nov 23–27).

Key Themes: Gold-Standard Construction, Retrieval Metrics, Model Interpretation, Data Storytelling, MLOps, MLflow Deployment, Special Topics.

🎓 Phase Outcomes

By the end of this phase, you will be able to:

  • Construct student-built gold-standard evaluation sets and compute retrieval and WER metrics.
  • Interpret and apply trained models to live or held-out data streams.
  • Design compelling data stories and interactive dashboards for result presentation.
  • Deploy data science pipelines using MLflow tracking, PaaS/IaaS, and MLOps principles.
