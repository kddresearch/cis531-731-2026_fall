Phase 1: Foundations & Tooling

Course Orientation, PySpark Fundamentals, Containerization & AI Tooling Baselines

Phase Overview

Establishing rigorous foundations in reproducible data science, distributed computing via Apache Spark, software engineering hygiene, and containerized tooling environments under the OSEMN framework.

Key Themes: FAIR Guiding Principles, RDDs & DataFrames, Catalyst Optimizer, Docker & DevContainers, AI/LLM Tooling Baselines.

Assigned Readings: Wilkinson et al. (FAIR), Danchev (Reproducible DS), VanderPlas (Python DS), Irving et al. (RSE Python), Brett et al. (RSE), Docker Docs, LiteLLM Proxy, Milvus Quickstart

🎓 Phase Outcomes

By the end of this phase, you will be able to:

  • Initialize and manage distributed Spark sessions and execute RDD transformations and actions.
  • Enforce explicit DataFrame schemas and leverage the Catalyst optimizer for relational querying.
  • Design reproducible development environments using Docker containers and DevContainers.
  • Configure local AI/LLM tooling baselines, vector database connectors, and proxy gateways.
