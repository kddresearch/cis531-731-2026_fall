Phase 2: Obtain & Ingest

Phase Overview

Phase 2 covers data acquisition and stream processing, focusing on ASR stream capture, VDB corpus acquisition, and Structured Streaming ingest architecture with event-time windowing, watermarks, and checkpointed fault tolerance.

Key Themes: Data Acquisition, ASR Ingress, Vector Database Sourcing, Structured Streaming, Event-Time Windowing, Watermarking, Fault-Tolerant Checkpointing.

🎓 Phase Outcomes

By the end of this phase, you will be able to:

  • Configure fault-tolerant streaming consumers and batch micro-batch ingestion pipelines.
  • Implement event-time windowing, watermarks, and stateful aggregations using Spark Structured Streaming.
  • Enforce source whitelists and stream contracts (`deal` pre/post-conditions).
  • Manage raw landing zones and WORM/append-only structured logs.
