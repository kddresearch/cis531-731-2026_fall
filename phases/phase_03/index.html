Phase 3: Scrub & Embed

Chunking, Embedding Generation, VDB Schema Design, and Few-Shot Trope Classification

Phase Overview

Phase 3 transitions the course from raw stream ingestion into the core data-cleaning, chunking, and vector-database representation stages of the OSEMN pipeline. Students analyze chunking cost models, approximate-nearest-neighbor index trade-offs (FAISS/Milvus), and prompt-engineered few-shot LLM classification workflows.

Key Themes: Chunking Strategies, Vector Database Schemas, FAISS Indexes, Few-Shot In-Context Learning, Trope/Genre Classification.

🎓 Phase Outcomes

By the end of this phase, you will be able to:

  • Derive storage and overlap costs across fixed-window, sentence-boundary, and structure-aware chunking strategies.
  • Evaluate index trade-offs between exact inner-product search and approximate-nearest-neighbor methods (IVF, HNSW).
  • Design provenance-bearing vector records with strict JSON Schema validation and contract enforcement.
  • Implement few-shot in-context learning pipelines with rigorous prompt formatting and label-space constraints.
